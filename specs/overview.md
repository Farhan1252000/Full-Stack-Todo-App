# Todo Full-Stack Web Application - Overview

## Project Purpose
To create a comprehensive full-stack Todo application that demonstrates modern web development practices with authentication, CRUD operations, and responsive UI.

## Current Phase
Phase II: Todo Full-Stack Web Application

## Technology Stack
- **Frontend**: Next.js 16+, TypeScript, Tailwind CSS
- **Backend**: FastAPI, Python 3.11+
- **Database**: Neon PostgreSQL
- **Authentication**: Better Auth
- **Development**: Docker, Git

## High-Level Features
- User authentication (signup/login/logout)
- Task management (create, read, update, delete, toggle completion)
- Multi-user isolation (users see only their own tasks)
- Responsive UI for desktop and mobile
- JWT-based secure session management
